# HW3 Automated Tests

This repository contains automated tests for HW3. It includes:

1. **HW3.java** – A class with a `main(String[] args)` entry point.  
2. **Five test methods** in `HW3.java`:
   - `testPostEmptyQuestionOrAnswer()`
   - `testPostValidQuestionOrAnswer()`
   - `testFilterResolvedNone()`
   - `testFilterResolvedAnswersExist()`
   - `testMarkAnswerAsResolved()`

## How to Build and Run

1. **Open** this project in Eclipse (or any Java IDE).  
2. Ensure you have the classes `Answer`, `Answers`, `Question`, `Questions` in the `QuestionAnswerSystem` package accessible on the classpath.
3. **Right-click** on `HW3.java` → **Run As** → **Java Application**.
