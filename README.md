# Individual-Homework3
HW3 Automated Tests
This repository contains automated tests for HW3. It includes:
HW3.java – A class with a main method as the entry point
Five test methods in HW3.java:
•	testPostEmptyQuestionOrAnswer()
•	testPostValidQuestionOrAnswer()
•	testFilterResolvedNone()
•	testFilterResolvedAnswersExist()
•	testMarkAnswerAsResolved()
How to Build and Run
1.	Open this project in Eclipse or any Java IDE
2.	Ensure you have the classes Answer, Answers, Question, and Questions in the QuestionAnswerSystem package accessible on the classpath
3.	Right-click on HW3.java, then select Run As, then Java Application
You should see console output with the pass or fail status of each test
